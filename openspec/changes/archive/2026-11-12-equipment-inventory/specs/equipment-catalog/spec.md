# Spec Delta

## Purpose

Catalogo integrato degli oggetti comuni di Pathfinder 1E (armi, armature, scudi, attrezzi), generato da uno script di import e disponibile senza import manuale.

## ADDED Requirements

### Requirement: Built-in item catalogue is loaded lazily
The app SHALL include a built-in catalogue of mundane items loaded once at bootstrap together with spells and feats. Components that depend on the catalogue SHALL show a loading state until it is available.

#### Scenario: Catalogue available after bootstrap
- **WHEN** the app finishes loading built-in data
- **THEN** the item catalogue can be browsed from the inventory without any manual import

### Requirement: Catalogue categories
The catalogue SHALL contain at least: simple, martial and exotic weapons (melee and ranged), ammunition, light, medium and heavy armor, shields (including tower shield), and adventuring gear. Each entry SHALL have a stable id, an Italian name, a category, a price in gold pieces, a weight in kilograms and a link to its source page.

#### Scenario: Browse by category
- **WHEN** the user filters the catalogue by "Armature pesanti"
- **THEN** only heavy armors are listed, each with name, price and weight

#### Scenario: Source link
- **WHEN** the user opens the detail of a catalogue entry
- **THEN** a link to the entry's page on the source wiki is shown

### Requirement: Weapon data
Each weapon entry SHALL include: proficiency group (simple, martial, exotic), handedness (light, one-handed, two-handed, ranged), damage dice for Small and Medium size, critical threat range and multiplier, range increment in meters (if any), damage types (bludgeoning, piercing, slashing, possibly more than one) and special properties.

#### Scenario: Longsword data
- **WHEN** the catalogue entry "Spada lunga" is read
- **THEN** it is a martial one-handed weapon with damage 1d6 (Small) / 1d8 (Medium), critical 19–20/×2, slashing

### Requirement: Armor and shield data
Each armor and shield entry SHALL include: category (light, medium, heavy, shield, tower shield), armor or shield bonus, maximum Dexterity bonus (or none), armor check penalty, arcane spell failure chance, and whether it is made of metal.

#### Scenario: Full plate data
- **WHEN** the catalogue entry "Armatura completa" is read
- **THEN** it is heavy armor with armor bonus +9, maximum Dexterity +1, armor check penalty −6, arcane spell failure 35% and metal

### Requirement: Reproducible import
The catalogue SHALL be generated by a versioned import script that reads the source wiki tables and writes the catalogue file. Re-running the script SHALL produce a catalogue with the same ids for unchanged entries. The script SHALL limit its request rate and SHALL NOT copy item descriptions.

#### Scenario: Regenerate catalogue
- **WHEN** a developer re-runs the import script
- **THEN** the catalogue file is regenerated and existing entry ids are preserved
